# Kịch bản lời đọc · ElevenLabs

**Cách tạo giọng**
- Model: **Eleven v3** (hiểu các tag biểu cảm trong ngoặc vuông `[...]`; tag không bị đọc thành tiếng).
- Ngôn ngữ: Tiếng Việt. Stability: **Natural**.
- **Mỗi đoạn xuất thành 1 file riêng**, đặt đúng tên file ghi ở đầu đoạn, chép vào `film/public/voice/`.
  Phim tự canh hình theo độ dài từng file → không cần chỉnh thời gian bằng tay.
- Dấu `...` = ngập ngừng tự nhiên; `[short pause]` / `[long pause]` = nghỉ ngắn / dài.
